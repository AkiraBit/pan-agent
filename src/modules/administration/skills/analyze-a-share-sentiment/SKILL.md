# A股市场情绪周期分析

优先服务于 PanWatch 情绪策略台的总览，同时保留 Codex 的分析、复盘与研究用法。PanWatch 模式先读 [总览数据契约](references/panwatch-overview.md)，通过宿主校验工具返回结构化结果，由确定性模板生成结果页。基础行情使用长桥 MCP；用户已授权 PanWatch 使用扶摇补充专项数据，逐项列明来源，不混用分母。其他宿主新增数据源前确认授权和实际工具能力。

需要独立结果页时读 [综合结果页](references/result-page.md)，先形成 JSON，再运行 `scripts/render_report.py` 生成离线 HTML；不让模型自由拼接页面代码。

默认交付一份可直接阅读和使用的综合看板：明确今日评价、周期定位、主要矛盾、今日应对、明日预判和左右侧条件预案。分析者负责综合裁决，不能把原始资料堆给用户自行判断。用户已要求策略结果页时，应提供具体观察对象、触发和取消条件；阶段名本身不能直接推出固定仓位或胜率。

## 结果优先（所有日常输出适用）

- 按参考结果页的阅读顺序组织：**结论区 → 明日预判与边界 → 明日操作 → 左右侧买点聚焦 → 情绪数据**。正文先结论，随后两三条最有解释力的事实。
- 写“退潮延续，封板改善不足以抵消亏钱扩散”，不要只摆出两个数字让用户裁决。写出基准判断，并说明哪一种实际变化会推翻它。
- 用交易者熟悉的语言：弱修复、接力收缩、梯队断层、局部抱团、轮动、承接。G/A/P/R、代理口径、接口、实测、校验、研究状态都是内部分析组织，不作为正文栏目。
- 数据来源逐项保留在结构化证据中，集中放在页尾默认收起的“数据来源与判断依据”；正文不堆链接、备注、工具名或参数研究史。
- 先查现有长桥与扶摇接口。最新复盘可直接用供应商板块指数历史比较板块走势，不需要先补齐全部历史概念成分；当前成分和涨停原因可以解释当前候选。仅在重建历史成员扩散或严格回测时需要历史成分。
- 关键数据缺失时，先向用户一次说清缺少的数据、所需字段和影响的栏目，等补齐再生成正式结果页。不要用一页“无法判断/待补充”替代结果。可省略的辅助项不拖住已能完成的判断。
- 不虚构用户实际仓位、成交、过去登记的计划或周期天数。条件未触发写“等待”；没有值得选的候选写“暂无符合条件标的”，不要凑数。

## 选择工作方式

- `overview`：PanWatch 总览。使用长桥交易日历确定最近已有行情的交易日，盘中使用当日已发生数据，开盘前及休市使用最近已结束交易日。界面展示最新状态和行情时点，不要求用户选择分析版本。
- `report`：完整综合结果页。按参考图生成结论、周期图、明日预判、情景边界、操作计划和候选聚焦；来源与口径默认折叠；可从 PanWatch 的源 JSON 直接生成。
- `snapshot`：指定时点或最近完整交易日的状态。未指定日期时，按交易日历确定最近完整交易日；标明 Asia/Shanghai。
- `intraday`：盘中快照。标明行情时点、延迟和未完成部分；成交额只与历史同一时刻比较，收盘指标保持暂定。
- `review`：收盘复盘或历史回放。历史结论按当时可知资料形成；事后结果放在独立的结果检验中。
- `research`：验证参数、信号或策略。先固定定义、样本和评价方式，再读取留出结果。

首次使用指标或接入数据时读 [数据与指标](references/data-and-metrics.md)；判断阶段、题材与七项视频补充时读 [判断方法](references/interpretation.md)；使用数值阈值前读 [参数与依据](references/parameters-and-evidence.md)。需要结构化输出或回测时读 [输出与研究](references/report-and-research.md)。引用本轮历史结论时读 [首轮实证](references/study-2026-11.md)，不要默认加载全部原始证据表。

## 必须保留的口径

1. 指数背景、短线情绪、题材/风格分别分析。主板、创业板、科创板、北交所分别展示覆盖，不能用主板结果代表所有板块。
2. 先确认 `as_of`、数据覆盖、股票池及制度版本。每个主要事实附来源和时点。区分事件发生、数据发布、抓取时间；历史数据重建不冒充原始发布版本归档。
3. 无样本、字段缺失、未成熟结果、相互矛盾分别标记；不填成零，不合并为“稳定”。辅助项不足时省略该项；正式结果页所需关键输入缺失时，列明补充要求并暂停生成。
4. 历史股票池包括当时存在且后来退市的股票；ST、停牌、新股特殊交易期、退市整理与无涨跌幅限制状态按当时处理。当前名单不能无说明地用于历史回测。
5. 涨跌停优先使用当日真实限价；用日线与历史制度推算时显著标注代理口径。不能统一用涨幅 9.9% 识别涨停。日线只能识别触板与收盘是否封住，不能恢复开板次数、封单和可成交性。
6. 股票池在信号产生或比较开始时冻结；保留后续失败、停牌与缺失成员的记录。不能根据事后涨跌重选“核心”，或只保留最终赢家。
7. 保留事实、解释、工程默认和经验/实证支持的区别。教学视频的说法与假设案例是来源内容，不是交易指令或实证证明。

## 执行分析

**先核验数据，再形成判断。** 优先使用可用的行情连接器、交易所资料和已有缓存；覆盖不足时使用已授权补充源，并逐项标明来源。使用代码计算统计量，保留输入口径、分母及缺失情况。数据接口不可用时使用可审计替代来源或报告局限，不编造缺失数值，也不为日常复盘自动下载全部历史市场数据。

按 G/A/P/R 组织证据，不合成为未经校准的“情绪总分”：

| 组 | 主要观察 | 解释约束 |
|---|---|---|
| G：参与广度 | 涨跌家数、净上涨比例、收益分布、均线上方比例、20/60日收盘新高/新低 | 指数和局部龙头不能代替横截面；历史不足的指标使用自己的有效分母 |
| A：进攻与接力 | 涨停占比、触板与收盘封板、首板/连板梯队、冻结队列的晋级 | 20%/30%板块不与10%主板混算；数量增长不自动等于承接质量改善 |
| P：行为反馈 | 昨日涨停、收盘未封住、高位与预先定义信号池的后续收益 | 拆分开盘、全天、盘中反馈；正收益存在不等于盈利正在扩散 |
| R：损伤与风险 | 跌停占比、大跌分布、下尾损失、前强势组受损范围 | 微小计数变化不能机械否决其他证据；严重扩散即时报告，不等阶段确认 |

成交额、换手和指数用于解释背景。成交放大可能伴随上涨扩散，也可能伴随恐慌；成交额不是资金净流入或统一资金主体意图。

对关键指标同时报告**水平、较上一交易日变化、相对近期基准变化**。历史分位数排除当日并正确处理并列值。历史没有充分支持的窗口、阈值和变化幅度保持可配置。

独立输出以下内容：

- **方向**：改善 / 稳定 / 恶化 / 分化 / 数据不足。说明参照时点和哪些组支持、哪些组反对。“仍弱但改善”是合法结果；稳定需要可用且变化不明显的证据。
- **双轴**：亏损是否缓和，盈利是否存在且正在扩散。分别列昨日变化与近期基准；不要把大跌后明显减亏掩盖在三日中位数中。
- **阶段**：低迷/冰点、修复、发酵/扩张、高热、分歧、退潮，可保留混合和备选解释。标明候选、支持较充分、冲突或数据不足；不强迫走完固定循环。
- **题材结构**：优先比较板块指数近期涨跌、当前涨停聚集与核心股梯队，直接判断持续、轮动或局部抱团。历史成员扩散另需可靠历史成分；不要把该研究要求误套到最新板块复盘。
- **验证条件**：下一观察时点、哪些证据会加强当前判断、哪些会推翻它。用户未要求交易策略时，不延伸为固定仓位或下单建议。

## 1.0 的实证约束

- 本轮主检验使用沪深主板、当日非ST、上市满60个市场交易日的研究池，2021—2025年共1,212个交易日；这不是所有任务通用的上市天数过滤。
- 四组各取一个代理指标的固定预测模型没有显示稳定优于简单基准的证据；不能宣称整套阶段识别已有预测准确率。
- “减亏但前涨停池仍无正反馈”与“两方面均较好”在2024—2025年有区分，但样本支持不能升级为必然反转或获利规则。
- 1/2/3日确认与60/120/250日分位窗口均无已证实的通用最优值。保留候选与确认层，风险提示不等待连续两天。
- 放量突破的1.2/1.5/2.0倍成交额门槛没有证明越高越好。它们可用于定义观察队列，不能作为独立看多门槛。
- 科创板的昨日涨停池在本轮1,212日中有632日无样本。P不可用时保留G/A/R观察并降级结论，不能将P填零或照搬主板阈值；替代强势池需另行定义、冻结和检验。

具体数字、边界和来源见参数表与实证文件。日常输出以本次事实为中心，不必重复整段历史说明。

1.0形成于2026年。将它用于更早日期属于用当前方法重建过去，不代表当时已经掌握本技能的研究结论。严格盲回放或新样本外验证应隔离未来材料并另选未参与本版本开发的数据；已读过相应事后案例时如实标为非盲复盘，不能声称未接触未来信息。

## 交付前自检

检查：结论与时点一致；股票池和分母可查；缺失未变成零；完整/盘中/代理数据标识清楚；事实与假设分开；阶段有反证；未来窗口已经成熟；统计收益没有被写成可成交收益。按用户需要提供简报、逐日复盘表、图表或可复查计算附件。
