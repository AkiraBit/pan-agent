# 综合结果页与连续验证

## 输出路径

PanWatch 仍以最新交易日为默认总览。模型只提交 `overview.schema.json` 的判断字段，宿主补齐行情、验证结果和来源，前端可导出完整 JSON 与离线 HTML。Codex 独立使用时也先组织同一信封，不依赖 PanWatch 服务：

```sh
python3 scripts/render_report.py --input /absolute/path/overview.json --output /absolute/path/sentiment-report.html
```

输入须为完整总览信封：`trade_date/as_of/collected_at/analyzed_at/run_id`、`analysis`、`metrics`、`coverage`、`evidence`；可含 `supplement`、`report`、`skill`、`model_label`。直接使用 PanWatch 导出的 JSON 可保留冻结条件及修订记录。只有分析对象时，先补齐真实计算字段；缺数据标缺失，不能用示例冒充市场事实。模板仅转义渲染，不取数、不运行交易、不证明分析正确。JSON 与 HTML 同时交付；HTML 是快照，不自动更新。

## 结果页的判断层次

1. **当前结论**：方向、阶段或相邻区间、证据状态。日内修复可与中期退潮并存；“强混沌”等风格描述可写在解释中，不擅自增加第七阶段或生成总分。
2. **市场与结构**：指数背景、G/A/P/R、损伤与扩散分开。最高板同时看各板数人数、断层、首板比例、前日冻结晋级；不能由一个高标推导梯队健康。
3. **连续验证**：P 日先登记对象、名单、指标、方向、阈值、目标交易日和发布时点；T 日仅用目标窗口可知数据检验。支持、反证与无法验证均保留。
4. **修订**：保留原发布判断与本次判断，写明新增证据。回溯解释可以存在，但不能覆盖当时标签，也不能用修订后的标签评价原预测。
5. **下次条件**：对象、窗口、加强条件、反证条件。条件冲突时先显示反证；条件未成熟保持等待，缺数据保持无法验证。结构观察不是交易指令。
6. **边界**：具体缺什么、影响什么、需要哪个接口；参数依据和验证状态分别展示。

## 可计算条件

`next_checks.rule` 和 `invalidation_rule` 可为 null；文字条件保持人工复核，不由 LLM 宣布程序验证通过。数值条件支持 `positive_ratio`（0–1）、`median` / `p10` / `feedback_mean`（百分点），比较 `gt/gte/lt/lte`，保留 `value/basis/calibration=unvalidated`。有数值规则时 `verification_window=next_session_close`；文字观察为 `qualitative`。自动验证窗口固定下一交易日收盘；盘中条件用文字表达并保持 null。这是工程范围，不是最佳交易持有期。

宿主冻结登记时间、来源 run、目标日、股票池 hash 和覆盖。完整且相同股票池才比较；前强势组反馈还须有可用冻结队列且无缺员。跳过目标日不能拿后一天代替；同日刷新保留前日登记集合。某条件达到阈值，只证明对应观察成立，不证明阶段预测或收益。

## 交易可行性

普通 A 股当日新买入部分不能同日卖出；按当时适用制度和可卖数量处理。撤单仅涉及未成交部分，不能把“撤单”“退出观察池”和“卖出持仓”写成同一操作。来源：[深交所交易规则（2026 年修订）3.1.4–3.1.5、3.2.6](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。

确认回封发生后才能产生依赖回封的信号；不能用后续回封确认，回填此前低点成交。一字板、涨跌停排队、报价缺口、滑点、费用和T+1均需进入单独策略回测。总览未读取账户时，不生成“实际空仓0%”“已成交”“今日最优交易”等事实。模板不默认仓位比例。

## 补充源口径

长桥负责基础广度与报价。扶摇 REST 可按实际启用的数据源补充涨跌停 / 炸板池、精确板数、供应商封板汇总和龙虎榜。接口不可用时保留长桥分析并报告专项缺口，不切回其他源。

- [涨停强度接口](https://fuyao.aicubes.cn/docs/api-reference/limit-up-statistics/)的 `page_boards` 与 `exact_boards` 分开。`five_plus` 是合并档位，不能转成精确五板；未返回板数不能无条件填零。页面晋级率不是已冻结队列晋级率。
- 池按请求交易日绑定，完整分页、去重和证券状态过滤分别记录；ST、新股未知状态保留在排除项。供应商汇总与过滤后样本不能共用分母。时间戳是采样时间，不能冒充历史原始发布时间。
- 龙虎榜按单日和多日区间分开；同股不同区间不合并净额。上榜买卖记录不是全市场资金流，不能据此识别实际控制资金或断言其意图。
- 当前概念标签、涨停原因可解释个股背景；不等于当时全市场概念成分，不据此确认历史题材持续性。补齐历史成分与冻结登记池后才验证板块扩散。
- 分时和封单快照不能恢复完整回封事件序列或保证排队成交。

## 参数与依据

借鉴参考结果页的是分层解释、预登记、反证和执行可行性检查。参考页的 4200 家、1.5 万亿、65% 封板率、炸板 40、跌停 10、晋级 20%、连续 2 日、试仓 1/8、龙虎榜 1.5 倍等未获得可审查回测，**不作为默认交易规则**。新阈值需登记研究样本、收益窗口、交易约束、基准和样本外结果；没有验证不能提升为“已证实”。原 1.0 研究结论只适用于其原始定义和样本，不能借给新增接口或规则。
