# 参数与依据登记表

将“依据来源”和“验证状态”分开：制度/数学定义可以有明确依据，但不能据此证明预测收益；教学经验可以启发观察，但不是统计证据；首轮实证只适用于已测试定义与样本。所有来源按本次分析时点核对。

## 使用中的初始配置

以下是可配置的观察起点，不是已证实最优参数：

```yaml
percentile_window: 120
percentile_min_valid_history: 60
percentile_extremes: [0.20, 0.80]
change_comparisons: [previous_session, previous_3_session_median]
stage_persistence_hint_sessions: 2
evidence_group_coverage_hint: 2
close_high_low_windows: [20, 60]
ma_window: 20
turnover_amount_baseline_window: 20
return_distribution_quantiles: [0.10, 0.50, 0.90]
mature_forward_horizons: [1, 3, 5]
minimum_material_change: null
calibrated_stage_probabilities: null
```

`null`表示尚未校准，不表示0阈值或0概率。风险变化结合实际幅度、影响面和其他R证据解释，不用“零容忍的单指标变坏”自动否决综合改善。报告所用配置与偏离默认的原因。

## 已有明确依据的口径

| 规则 | 依据 | 可据此主张什么 |
|---|---|---|
| 使用当日适用的板块、风险和特殊交易制度 | 交易所按日期生效的规则、证券状态 | 正确的涨跌停/交易约束口径；不推出盈利能力 |
| 参考窗排除当日、队列先冻结、未来结果成熟后评价 | 时间顺序和统计定义 | 避免相应的前视/选择错误；不能消除所有数据修订问题 |
| 高低点使用可比价格，真实限价使用原始价格 | 除权和价格约束的计算含义 | 避免将价格调整误当成破位或涨跌停 |
| 缺失不是零，零事件比例分母为0时不可用 | 数学定义与样本语义 | 正确处理不可计算值 |
| 并列分位采用中间秩 | 经验分布的明确约定 | 零跌停长序列不会被判为最高分位 |
| 指数、板块、冻结队列和市场广度分层 | 测量对象不同；视频经验；历史案例 | 支持分别观察，不能证明单一因果 |

## 待测参数及本轮结果

数值来自2026-11-15研究；细节、限定和证据见[首轮实证](study-2026-11.md)。以下“支持”不等于已证明普适或可交易。

| 项目 | 本轮比较/覆盖 | 当前结论 | 1.0处理 |
|---|---|---|---|
| 历史分位窗口 | 60/120/250日，同一主板可用日期 | 未确定跨时期稳定最优；科创板60日窗在留出期无完整四组可用日期 | 保留120初始值，报告有效历史与板块差异 |
| 极端冷热阈值 | 10/90、20/80、30/70 | 热区后续可以继续上涨，冷区不稳定反转 | 用于描述相对位置，20/80保持暂定 |
| 变化参照 | 昨日、前三日、前五日中位数 | 排名随年份改变；三日参照会漏报冲击后的同比昨日减亏 | 昨日变化与三日位置同时报告；新并行设计未独立重测 |
| 连续确认 | 1/2/3日，分别检验持续改善与阶段同名 | 无通用最优；三日显著减样本；严格同标签两日使主板70.5%日期未确认 | 2日仅作持续性提示，风险即时报告 |
| 支持组数 | 2组/3组 | 三组筛选未证明稳定优于两组，且样本更少 | 至少两组作为覆盖提示，不当统计独立性或概率 |
| 新高/新低窗口 | 前20日/前60日收盘高低点 | 有不同时间尺度信息；增量预测结果随年份/板块改变 | 同时展示近端与背景，不宣称哪一窗最优 |
| 风险/盈利双轴 | 三日减亏代理 + 前涨停池正反馈 | 2024—2025年有区分，2023年差距较小；仅减亏组样本有限 | 保留双轴，区分盈利存在与扩散；不当反转信号 |
| 放量门槛 | 20日突破且成交额倍数1.2/1.5/2.0 | 三个门槛下5日相对表现均弱于同日主板池，倍数加大未改善 | 作为队列描述；不设置默认“倍数越大越看多” |
| 结果窗口 | 1/3/5个交易日 | 均已统计，不等于已经选择最佳持有期 | 用于已成熟反馈；10日等其他窗口仍待研究 |
| MA20、成交额20日中位、10/90尾部分位、−5%大跌 | 作为固定测量口径使用 | 未比较这些参数的最优性 | 标为工程默认/待校准，不列为已验证阈值 |
| 最少60个历史有效观察 | 固定使用，未比较其他最小样本要求 | 不能保证稳定性；零事件可导致覆盖不足 | 报告有效日期与事件数，不制造“达到60就可靠”的规则 |
| 研究股票上市满60日 | 研究池过滤，未做对照 | 不是市场分析的通用门槛 | 只在复现研究时照用；新股观察另列 |
| 阶段优先级、最近5日记忆、40/60中间边界 | 前两者仅为研究操作化；40/60未独立检验 | 没有外部阶段真值或稳定最优依据 | 不写死相位转移；保留重叠与备选解释 |
| 变化幅度/风险否决阈值 | 只暴露了零幅度判断的边界，未做参数网格 | 2024-09-24的微小跌停差异曾使机械方向模型输出分化 | 增加幅度语境；具体数值仍待测 |
| 核心/跟随规则、题材起点 | 缺可靠历史题材成员及传播时间 | 尚未验证 | 只能用事前可知规则，缺数据留空 |
| 匹配对照、个股/题材/风格归因 | 首轮只做同板块参考与分板块观察 | 未完成完整匹配和因果识别 | 输出诊断线索，不能写成环境导致亏损的证明 |
| 真实策略收益 | 未定义并回测完整成交/退出/费用/仓位 | 未验证 | 不输出策略年化、夏普或自动仓位映射 |

## 应保留为假说的说法

“高热必见顶”“冰点必反转”“核心未倒就安全”“后排先弱必退潮”“全网讨论时已太晚”“退潮时全部技术信号失效”均不作为规则。把它们改写为可观察的条件、反证和待测试的具体队列。

未经新的独立检验，不把本轮看起来最好的配置更新为“已验证最佳”。1.0基于发现增加的幅度语境、并行变化比较、非互斥阶段表达和板块降级是工程修订，仍须前向使用或新的留出区间检验。

## 1.2 结果页新增项

数值条件的次日收盘验证、覆盖一致性校验、反证优先与历史发布保留是可测试的工程规则，不能当成预测能力已验证。参考结果页阈值均不默认启用，详见[综合结果页](result-page.md)。长桥强弱代理（5% / 10% / 15%）、扶摇页面档位晋级率与新的冻结条件尚无独立样本外收益验证。
