# 数据源调用约定

新增页面、任务或 Agent 工具时，先确定使用哪家供应商和哪个官方接口。调用方提交供应商、操作 ID 和该接口自己的参数，并按该供应商的响应字段处理业务。具名调用不会自动换源。

Python 调用入口：

```python
from src.platform.marketdata import source_calls

result = await source_calls.call(
    "fuyao", "get_a_share_prices_snapshot", params={"thscodes": "600519.SH"},
)
# result["response_json"] 是上游 JSON 文本。消费方解析并处理所需字段。
```

`source_calls` 在发起请求前检查目录、来源总开关、接口开关、凭证和参数。仅允许调用已注册接口，调用方不传 URL 或 API Key。请求由供应商客户端处理超时、响应大小限制和密钥脱敏；返回的 `response_json` 不转换财务或行情字段。`http_status`、`business_code` 保留上游状态，本地拦截与传输失败通过带原因的 `CallError` 报告。FTShare 可以用 `variant` 选择已登记的路径。REST 目录和 Agent 的 REST 查询共用这条路径；Agent 接口过大的响应需要缩小范围或分页后再取。

目前已注册 FTShare 和同花顺 REST。FTShare 与同花顺都按单个官方接口控制。其他提供方需要具名接入时，在数据源层登记操作、可用范围和开关归属，并补齐该供应商自己的请求验证和调用实现。

现有页面的 `MarketData` 等接口继续服务既有消费方，原有的标准结构和已约定的主备行为维持原样。新增明确了供应商的功能使用上面的具名入口。
长桥的授权、查询工具和技能由「MCP 与技能」独立管理。行情引擎和 ETF 自动采集不再通过长桥 MCP 请求数据；已有历史记录仍保留。

在财联社、新浪财经、东方财富和腾讯财经的接口设置中，测试参数与业务配置分别保存。当前使用的是各网站接口，未找到与这些具体路径对应的公开接口规范，参数按代码中的实际请求及解析核对：

- 财联社电报、新浪 7×24、东方财富快讯使用 `rn`、`page_size`、`pageSize` 控制条数，测试默认 20 条，不传证券代码。
- 腾讯、东方财富日 K 线默认最多展示每个标的 30 条。东方财富适配器会请求较宽的历史窗口再截取结果。
- 东方财富事件测试传递 `page_size`，测试默认 100；回溯天数是本地过滤窗口。龙虎榜的默认日期取本地交易日历最近一个已收盘的交易日。
- 支持证券代码的测试只接受相应适配器覆盖的市场。ETF 只接受沪深 ETF 代码，截图等待时间是应用参数。
