# Tushare 数据源

在 **设置 → 数据源服务商 → Tushare** 粘贴 Token（Python 示例中 `ts.pro_api('...')` 的引号内内容），保存后打开 **数据源 → Tushare**。Key 加密保存在服务端，页面只显示掩码。PanWatch 按 Tushare Pro HTTP 协议发起请求，当前中转地址为 `http://data.000666.site/dataapi`，请求时中转会收到该 Key。

接口目录按 [Tushare 数据接口文档](https://tushare.pro/document/2) 的顺序排列，共 148 项：

| 分类 | 数量 | 子分类 |
| --- | ---: | --- |
| 股票数据 | 106 | 基础数据、行情数据、财务数据、参考数据、特色数据、两融及转融通、资金流向数据、打板专题数据 |
| ETF 专题与业绩基准 | 18 | 含公募基金业绩基准库 |
| 指数专题 | 24 | 文档直接列出接口 |

接口的设置窗口提供示例参数、返回字段和对应的官方文档链接。「测试」使用已保存的参数，显示 HTTP 状态、Tushare 业务状态、行数和原始 JSON。可单独启停接口，也可暂停整个 Tushare 来源。接口访问权限、历史范围及实时数据可用性由所用 Key 和中转决定。

登录后的程序调用可先读取 `GET /api/datasources/tushare/catalog`，再请求 `POST /api/datasources/tushare/query/{operation_id}`。例如用 `daily` 查询单只股票的历史日线：

```json
{
  "params": {"ts_code": "600519.SH", "trade_date": "20251031"},
  "fields": "ts_code,trade_date,close"
}
```

`fields` 可省略，省略时使用上游默认字段。该目录供独立调用，不改变现有行情主备顺序。文档中的复权行情和通用行情两个页面使用同一个本地 SDK 函数 `pro_bar`，无法按 HTTP 接口调用；日线、复权因子及相关技术因子可通过各自的 HTTP 接口查询。

## 宽基 ETF 分时

仅使用 Tushare 行情。将两份观察名单合并去重后共 22 只，使用 `etf_basic` 核验上市信息并显示基金简称，使用 `mkt_idx_bmk` 核验宽基分类。Tushare 基准分类目录未收录创业板 50；华安创业板 50 ETF（159949.SZ）按[基金管理人披露的跟踪指数](https://www.huaan.com.cn/etf/159949/sgshqd.jsp)纳入样本，不计入 Tushare 目录统计。7 只样本已逐只核验中央汇金具名持有记录（各基金 2025 年年报第 9.2 节）；其余 15 只列为扩展观察。历史图按样本上市日期筛选，不代表所选日期的实际持有人。成交额是样本全市场总成交额，不能归因于特定机构。

- 当日使用 `rt_etf_min_daily`、`rt_idx_min_daily` 拉取开盘以来的序列；相邻分钟可使用 `rt_etf_min`、`rt_idx_min` 补一根，避免整日重取。
- 页面可见且正在查看当天行情时，按北京时间的图表分钟刻度刷新。默认在刻度后 12 秒查询；目标分钟尚未发布时，每次增加 6 秒，最多 42 秒。11:30 和 15:00 至少等待 32 秒。午休、历史日期和隐藏标签页不轮询。
- 历史使用 `etf_mins`、`idx_mins`，昨收来自 `index_daily` 的上一交易日记录。21:00 后尝试读盘后历史分钟；已有当日数据遇到上游缺口时保留。
- 按交易日保存样本和各标的分钟数据；同一天的并发读取合并，已归档的标的不再调用上游；观察样本扩展时，既有日期仅补采缺少的标的。Tushare 缓存与旧 FtShare 缓存分表隔离。
- 波动线下拉框分为「指数」和「ETF」：ETF 目录来自 `etf_basic`，指数目录来自 `index_basic` 的沪深交易所分类。两类都支持按名称或代码筛选并独立保存勾选状态；曲线相对各自当日首条可用分钟行情计算，不改变宽基成交额样本。ETF、指数的行情分开按交易日和代码入库；历史仅请求缺失的分钟区间，盘中相邻分钟优先增量查询。指数使用 `rt_idx_min_daily`、`rt_idx_min` 和 `idx_mins`，具体分钟覆盖受上游权限及指数代码影响。
- 顶部累计成交额用同一批 ETF、截至同一分钟的前 5 个交易日均值对比，高出或低于至少 20% 标记为明显放量或缩量。历史分钟行情按交易日和 ETF 入库，只补采缺失或尚未完整的日期；部分分钟也先保存。5 个交易日覆盖完整后，计算出的均值按所选交易日写入 `etf_tushare_turnover_baselines`。有效缓存随分时响应返回；ETF 样本、参考交易日或源成交额改变时再请求计算接口。
